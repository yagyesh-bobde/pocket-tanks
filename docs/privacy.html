Analytics & privacy

The published Pocket Tanks game uses PostHog to understand how many anonymous browsers visit, which sources bring them here, their approximate countries, browser/device types, and which game modes they play. The game has no login, so these statistics do not identify a visitor by name.

PostHog receives an anonymous browser ID stored in local storage, pageviews, session information, and basic events such as starting or completing a match. IP addresses are sent to PostHog as part of ordinary network requests and may be used for approximate geographic information. We do not send player names, room codes, saved matches, or form inputs. URL queries and fragments are removed. Session recordings and automatic click tracking are disabled.

Analytics runs only on the published game. Local development, LAN copies, and screenshot review scenes do not send events. Do Not Track and Global Privacy Control are respected. Blocking analytics does not prevent play.

This preference applies to this browser. Existing statistics are not erased by opting out. Clearing site data resets the preference and the anonymous browser ID.

Local preferences and saved solo matches stay in this browser. Two-device games send player names and game state to the other player using WebRTC; PeerJS provides connection signaling.
